# KNOCK · 노크

AI 기반 대화 회복 코칭 **프론트엔드 데모**. 선택한 **A · 세이지 클린** SVG를 기준으로 구현했습니다. 실제 LLM·STT·TTS API, 백엔드, DB, 로그인은 연결하지 않습니다.

## 실행

Node.js 20.19 이상 또는 22.12 이상 권장.

```sh
npm install
npm run dev
```

출력된 로컬 주소로 접속합니다. 프로덕션 빌드는 `npm run build`, 빌드 확인은 `npm run preview`, 서비스 로직 테스트는 `npm test`입니다. 정적 호스팅 시 모든 경로를 index.html로 보내는 SPA fallback 설정이 필요합니다.

## 기술과 구조

React 19, Vite 6, JavaScript, React Router 7, Lucide React, CSS. Context로 현재 세션을 관리하고 UI·더미 서비스·한국어 데이터를 분리했습니다.

- src/pages: 페이지 및 세부 화면
- src/components: 공통 카드·버튼·모달·내비게이션
- src/context: 세션, 선택, 저장 동의, 기록 관리
- src/services: 작성 시나리오 대화, 지표 계산, localStorage
- src/hooks: 브라우저 음성 인식·합성
- src/data: 목표·상황·페르소나·대화·코칭·미션
- reference/KNOCK_Design_3_Options: 제공된 디자인 원본
- tests: 핵심 데이터·안전·지표·저장 테스트

## 시연

1. 시작 → 목표·상황·페르소나를 각각 고릅니다.
2. 준비 → 마이크 안내 → 자신감 선택 또는 건너뛰기.
3. 텍스트를 입력하거나 ‘예시로 말해보기’를 누릅니다. 650ms 처리 상태 후 선택 상황의 다음 작성 응답이 나옵니다. 3개 장면 후 종료를 안내합니다. 도중 종료도 가능합니다.
4. 힌트, 쉬기·이어가기, 종료 확인을 이용할 수 있습니다.
5. 종료 → 자신감 → 현재 메시지로 계산한 리포트 → 장면 선택·재연습 → 실제 전후 발화 비교.
6. 현실 미션을 고르고 시도·미시도·보류와 선택 소감을 기록합니다.
7. 새 연습을 시작하면 이전 세션·선택은 초기화합니다. 동의한 저장 기록은 유지합니다.

## 실제 동작과 데모의 차이

입력·선택·라우팅·지표 계산·재연습 비교·미션 자가 기록·동의·기록 삭제는 실제 프론트엔드 동작입니다. 상대 응답과 추천 문장·피드백 예시는 미리 작성된 한국어 데이터입니다. 대화 내용의 의미를 이해하는 AI는 아닙니다. 목표는 화면의 작은 목표에, 상황과 페르소나는 상대 발화에 반영됩니다.
질문은 물음표 개수, 응답 길이는 공백을 제외한 유니코드 글자 수의 평균입니다. 시간은 세션의 경과 시간으로 쉬는 시간도 포함합니다. 침묵과 음성 응답 시간은 측정하지 않아 ‘측정 불가’로 표시합니다. 전후 발화 길이는 공백 포함 글자 수로 별도 비교합니다. 질문 수·길이를 대화의 질 점수로 해석하지 않습니다.

## 음성

SpeechRecognition/webkitSpeechRecognition 및 speechSynthesis 지원을 런타임에 확인합니다. 한국어 ko-KR을 사용하며 브라우저 권한·네트워크·기기 지원에 따라 다릅니다. 마이크를 누르면 권한을 요청합니다. 음성 읽기는 기본 꺼짐입니다. 미지원·권한 거부·인식 실패·음성 출력 실패 시 텍스트 안내를 제공합니다. 원본 음성 파일을 생성·저장하지 않습니다. 브라우저 제공사가 음성을 처리할 수 있으므로 실제 제품에서는 제공사 개인정보 정책을 검토해야 합니다. 실제 STT/LLM/TTS 연동으로 표시하지 않습니다.

## 저장과 삭제

기본값은 저장 미동의. 대화는 React 메모리에만 존재하며 새로고침하면 미저장 세션은 사라집니다. sessionStorage나 URL에 대화를 넣지 않습니다.
별도 동의 후 **새로 시작한** 세션이 완료된 경우에만 이 브라우저 localStorage의 `knock-demo-v1`에 텍스트·지표·재연습·미션 자가 기록을 저장합니다. 진행 중 동의를 켜도 과거 대화를 소급 저장하지 않습니다. 철회한 진행 세션은 다시 켜도 저장하지 않습니다. 동의 설정은 브라우저에 저장하며 기존 기록은 별도 삭제할 수 있습니다. 단일·전체 삭제는 확인 모달 후 실제 저장 데이터에서도 제거합니다. 삭제한 세션은 자동 재저장되지 않습니다. 저장 실패는 화면에 안내합니다. 가짜 과거 기록을 실제 목록에 넣지 않습니다. 서버·기기 간 동기화·암호화·서버 보유 기간 정책은 없습니다.

## 안전 데모

특정 자해·자살 표현을 단순 문자열로 찾는 데모입니다. 예: ‘죽고 싶어요’. 실제 위험 판정이나 의료 기능이 아닙니다. 오탐·누락이 가능하며 일반 역할극을 중단하고 안전 안내를 표시합니다. 감지된 입력은 대화에 추가·저장하지 않습니다. 해당 세션은 대화/재연습 경로로 되돌아가도 이어갈 수 없습니다. 음성 입력·지연 응답도 중단합니다. 안내 전화와 기관 링크는 구현 시 제공된 한국 지역 헬프라인 정보로 확인했습니다. 실제 운영의 감지·대응 정책과 정보 최신성은 별도 검토가 필요합니다.

## 반응형·접근성

모바일 원본을 기준으로 600px 이하 하단 내비게이션, 태블릿 축소 사이드바, 데스크톱 최대 너비 콘텐츠와 다열 카드로 확장했습니다. 데스크톱·태블릿 원본이 없어 해당 배치는 구현 제안입니다. 가짜 휴대폰 상태바는 웹에서 제외했습니다. 높이는 100dvh와 safe-area를 고려합니다. 모달 포커스 가두기·Escape·배경 스크롤 방지·포커스 복귀, 선택 버튼 aria-pressed, 폼 라벨, live 상태, 건너뛰기 링크, reduced-motion을 적용했습니다. 본문 보조색은 충분한 대비를 위해 원본 #748078보다 진한 #627068을 사용한 접근성 조정입니다. 폰트는 Noto Sans KR → Malgun Gothic → sans-serif 순으로, 외부 폰트를 요청하지 않습니다.

## 미확정·향후 연동

실제 세션·대화 API, 스트리밍 STT/LLM/TTS, 발화 기반 코치 AI, 의미상 질문·침묵 분석, 안전 판정·운영 대응, 서버 저장·삭제·보관 기간, 익명/계정 정책, 기관 연계는 별도 설계가 필요합니다. 사람 코치 예약·관리자·유료 기능은 범위에서 제외했습니다. 3개 장면과 650ms 처리 시간, 페르소나 문구, 데스크톱 배치는 데모 구현 선택이며 확정된 운영 정책이 아닙니다.
